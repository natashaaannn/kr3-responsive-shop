
# SpookyShop — Контрольная работа №3

## Описание проекта

SpookyShop — учебный многостраничный сайт интернет-магазина товаров для Хэллоуина, разработанный по дисциплине «Фронтенд и бэкенд разработка».

**Тема КР №3:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Проект создан на основе КР №1. В практическом занятии №12 сайт адаптирован для телефонов, планшетов и компьютеров без использования Bootstrap.

## Страницы сайта

- `index.html` — главная страница с приветственным баннером, правилами Хэллоуина, популярными товарами и блоком поддержки.
- `catalog.html` — каталог из 18 товаров с фильтрацией по категориям, статусу и цене.
- `product.html` — страница костюма скелета с фотографией, описанием, ценой и таблицей характеристик.
- `order.html` — форма оформления заказа.
- `contacts.html` — контактная информация, Яндекс.Карта, форма обратной связи и модальное окно обратного звонка.

## Используемые технологии

- HTML5 — структура страниц.
- CSS3 — оформление и адаптивная вёрстка.
- Flexbox — навигация и расположение элементов.
- CSS Grid — сетка товаров, каталог и формы.
- Media Queries — адаптация под разные экраны.
- JavaScript — базовые интерактивные функции сайта.
- Git и GitHub — хранение проекта и контроль версий.
- Chrome DevTools — проверка адаптивности.

## Практическое занятие №12

### Цель работы

Адаптировать многостраничный HTML/CSS-сайт для разных размеров экранов, используя собственные стили без Bootstrap.

### 1. Подготовка проекта

Создан отдельный проект `kr3-responsive-shop` на основе файлов КР №1.

Добавлен `css/responsive.css`, который подключён после `css/style.css` на всех пяти страницах.

На страницах используется метатег `viewport`.

### 2. Подход Mobile First

Основные адаптивные стили написаны для мобильных устройств.

Для более широких экранов используются медиазапросы:

- `640px` — переход к двум колонкам товаров.
- `768px` — адаптация навигации и двухколоночных форм.
- `1024px` — компьютерная версия с горизонтальной навигацией и тремя колонками товаров.

### 3. Главная страница

На `index.html` выполнена адаптация:

- шапки и навигации;
- приветственного баннера;
- заголовков и отступов;
- сетки популярных товаров;
- изображений карточек.

На телефоне товары отображаются в одну колонку, на планшете — в две, на компьютере — в три.

### 4. Каталог товаров

На `catalog.html` адаптированы фильтры и карточки.

На мобильных устройствах фильтры располагаются над товарами, на компьютере — слева.

Сетка каталога выполнена с использованием CSS Grid. Поля фильтров и кнопка применения подстраиваются под ширину экрана.

### 5. Страница товара

На `product.html` адаптировано расположение изображения и описания.

На телефоне фотография находится над информацией о товаре, на компьютере — слева от неё.

Таблица характеристик помещена в `.table-wrapper`. На узких экранах она прокручивается горизонтально внутри контейнера, не расширяя всю страницу.

### 6. Форма заказа

На `order.html` реализована адаптивная форма.

На телефоне поля расположены в одну колонку, на более широких экранах — в две.

Поля ввода имеют гибкую ширину и минимальную высоту 44px. Кнопка заказа также адаптируется под ширину устройства.

### 7. Страница контактов

На `contacts.html` адаптированы:

- контактные блоки;
- форма обратной связи;
- Яндекс.Карта;
- модальное окно обратного звонка.

На небольших экранах модальное окно ограничено размерами области просмотра. При необходимости его содержимое прокручивается.

### 8. Responsive Images

Для товаров созданы дополнительные версии изображений разных разрешений.

На страницах `index.html`, `catalog.html` и `product.html` добавлены атрибуты:

- `srcset` — выбор изображения подходящего разрешения;
- `sizes` — указание размера изображения в макете;
- `loading="lazy"` — отложенная загрузка изображений.

Для адаптации изображений также используется `max-width: 100%`.

Изменены изображения:

- `index.html` — 9 изображений товаров;
- `catalog.html` — 18 изображений товаров;
- `product.html` — главное изображение костюма скелета.

В зависимости от исходного размера для изображений подготовлены варианты шириной 240, 320, 480, 640 и 960 пикселей.

### 9. Проверка адаптивности

Проверка выполнялась через Google Chrome DevTools.

Проверены ширины:

- 360px — телефон;
- 768px — планшет;
- 1440px — компьютер.

Проверялись шапка, навигация, карточки товаров, фильтры, формы, изображения, таблица характеристик и модальное окно.

Загрузка адаптивных изображений проверялась через `Network → Img` с отключённым кэшированием.

При проверке изображения успешно загружались со статусом HTTP 200.

Также через `currentSrc` подтверждено, что браузер выбирает адаптивную версию изображения `skeleton-960.png`.

## Запуск проекта

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в Visual Studio Code.
3. Запустить `index.html` с помощью расширения Live Server.
4. Для проверки адаптивности открыть Chrome DevTools.

Дополнительные библиотеки для запуска не требуются.

Проект является учебным. Серверная обработка и сохранение заказов не реализованы.
