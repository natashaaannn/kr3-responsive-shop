# Учебный frontend-проект: Хэллоуинский магазин SpookyShop

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина праздничного декора и костюмов SpookyShop.

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог товаров (витрина из 18 товаров с расширенными фильтрами);
- `product.html` — страница карточки товара (флагманский костюм скелета с таблицей характеристик);
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл скриптов;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Дополнительные элементы
- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок в соцсетях.
- Интеграция API Яндекс.Карт - интерактивная карта магазина на странице контактов.

## Используемые технологии
- HTML5 (Семантическая разметка);
- CSS3 (Дизайн-токены, Grid Layout, Flexbox);
- JavaScript (Базовая валидация формы);
- Git;
- GitHub.

## Постановка контрольной работы №1
Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».
В рамках контрольной работы разработан многостраничный HTML/CSS-сайт интернет-магазина.
Проект включает в себя:
- главную страницу с интерактивным баннером и правилами Хэллоуина;
- страницу каталога с сеткой товаров и блоком фильтрации;
- страницу карточки товара с подробными характеристиками;
- страницу оформления заявки (модальное окно);
- страницу контактов с реальными демонстрационными данными;
- семантическую HTML-разметку и адаптивную графику;
- состояния элементов при наведении и фокусе (неоновые ховеры).

## Реализованные элементы интерфейса
- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация и обработка формы.

## БЭМ-структура проекта
В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## Использование Flexbox и Grid
В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.


## CSS-архитектура
В проекте используются:

- CSS-переменные в `:root` (дизайн-токены палитры);
- единая шкала отступов и скруглений;
- интерактивные состояния `:hover`, `:focus-visible`, `:disabled`;
- фиксированный многослойный задний фон (эффект Parallax).
